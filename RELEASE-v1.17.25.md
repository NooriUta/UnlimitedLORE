# LORE v1.17.25

Подпись встроенных графиков Völva ключом LORE, живая запись прогонов CI в гейты качества, честный вердикт и сводка проверок в kit для чужих приложений. Миграций схемы нет.

## Встроенные графики Völva

- **Токен встройки подписывается ключом LORE, Völva проверяет его открытым ключом** (SPRINT_VIZ_EMBED/EMB-L6, #1460). Повод: при общем секрете HS256 ключ держит и Völva, и утечка её конфигурации позволила бы подписать любую встройку (ADR-LORE-055-D7). Теперь подписывает только бэкенд LORE закрытым ключом ES256, а открытый ключ публикуется по адресу `GET /lore/embed/jwks`. Пока пара ключей не внесена в настройки среды, работает прежняя подпись HS256 как временная.

## Гейты качества

- **Прогоны CI записываются в гейты** (SPRINT_QG_REBUILD/QG-12, #1465). Повод: на проде опрос прогонов Actions не записал ни одного прогона — «записано 0 из 8068». Код читал поля прогона в форме GitHub, а Forgejo отдаёт их иначе, поэтому каждый прогон считался «без даты» и пропускался. Теперь прогоны пишутся с датой, ссылкой, коммитом и номером PR. Заход разбирает одну страницу (30) вместо всех тысяч прогонов: Forgejo не соблюдает лимит выдачи.

## Статусы

- **Отказ в пачке статусов называет причину** (SPRINT_LORE_WORK_ANY_KIND/WK-BATCH-EVIDENCE, #1464). Повод: `status_set_batch` при отказе гейта отвечал голым «HTTP 409», и причину приходилось выяснять отдельным вызовом. Теперь каждый отказ приходит с кодом и текстом, например `HTTP 409 DONE_BY_HUMAN_ONLY — …`.

## kit для чужих приложений

- **Честный вердикт** (SPRINT_UXR_S14_KIT5/K5-VERDICT-CONTRACT, #1458). Повод: пилот «Дата-странники» видел провал проверки без текста и «Все проверки пройдены» у записи, где проверок нет. Теперь провал показывается с текстом, «не смогли проверить» — отдельной группой, а у записи без проверок строки вердикта нет.
- **«Это часть» вместо ложной обрезки** (SPRINT_UXR_S14_KIT5/K5-LIST-TOTAL-TRUNCATED, #1458, #1467). Повод: список писал «выдача обрезана сервером», когда приложение само показывало часть записей, а вложенный список связи — «1 из 1292, обрезано». Теперь список пишет «это часть: в источнике N», а вложенный список считает только свои записи.
- **Поле-список и «Да/Нет»** (SPRINT_UXR_S14_KIT5/K5-FIELD-LIST, #1458; SPRINT_UXR_S14_KIT5/K5-MODEL-BOOL-FIELD, #1467). Повод: значения списка склеивались в одну строку, а логическое поле показывалось как «true». Теперь значения списка идут отдельными пунктами, а логическое поле — «Да/Нет».
- **Фильтр по проверке и сводка «прошло N из M»** (SPRINT_UXR_S13_KIT4/K4-VERDICT-FILTER, SPRINT_UXR_S13_KIT4/K4-SUMMARY-QUEUE, #1461, #1468). Повод: увидеть, какие записи не прошли конкретную проверку, можно было только перебором. Условие по проверке теперь хранится в адресе. Сводка показывает, сколько записей прошло, и причины провалов со счётом; причина открывает список ровно этих записей без перезагрузки страницы. Карточки сводки отсортированы по тяжести.
- **Раздел «Шильдики» в витрине kit** (SPRINT_UXR_S14_KIT5, #1458) — статусы, коды, типы, приоритеты и теги в одном месте, как материал для бренд-бука.
