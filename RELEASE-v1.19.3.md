# LORE v1.19.3

Хотфикс к 1.19.2: PR из репозиториев проекта привязываются к задачам и выпускам.
- PR из любого зарегистрированного репозитория проекта привязывается по своему адресу «owner/repo#N».
- У выпуска можно указать, в каком репозитории живут его PR.

## Исправления

- **PR из репозитория проекта привязывается к задаче и выпуску** (SPRINT_MINILORE_LINK_PIPE/LP-31, #1905).
  - Повод: PR сервера miniLORE (AIDA/miniLore_serverside) и кита (AIDA/miniLoremobilekit) не привязывались — LORE отвечал «git project not registered», потому что знал только репозиторий-тёзку проекта. Обхода не было: «#209 + проект» легло бы на другой PR с тем же номером.
  - Теперь «owner/repo#N» принимается, если owner/repo — проект или репозиторий из реестра LORE. PR хранится под адресом своего репозитория, поэтому одинаковые номера в разных репозиториях не склеиваются; название, адрес и состояние PR подтягиваются через проект репозитория.
  - У привязки PR к выпуску появилось поле `pr_repo` — репозиторий, в котором живут номера PR (в MCP — `fields.pr_repo`).
  - Ценность: работа в репозиториях-спутниках проекта (сервер, кит) видна в задачах и выпусках так же, как в основном репозитории.
