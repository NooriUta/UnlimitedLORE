Столбцы. Одна сетка на всю ленту — у всех строк тип, заголовок, код, время, место, автор, статус и «раз» стоят на одних вертикалях. Длинное режется многоточием, полностью — в подсказке.
Копия. Кнопки ⧉ нет. Щелчок по первой иконке копирует код записи, подсказка «скопировать код …».
Вид события. Только значок (релиз · изменено · появилось · статус); слово — в подсказке.
Новое. «НОВОЕ» не пишется на строке. Непрочитанное — сверху, жирным и с отметкой слева; затем одна линия «дальше — прочитанное».
Статус. Переход «было → стало» — свой столбец, стрелки на одной вертикали; «×N» — отдельный узкий столбец, у строки без повторов он пустой.
Кто. Агент — по-человечески: значок и имя агента с профилем («Claude Code · full», «Kimi · full»), учётка (lore-mcp-full) — в подсказке; человек — имя и аватар.
Время. Местное время; UTC — в подсказке, а не отдельным столбцом. «Без времени» — прочерк.
Код. Без префикса SPRINT_ (место уже есть в столбце «проект · спринт») — полностью в подсказке.
Телефон. Запись — карточка: сверху тип, что, заголовок (до двух строк) и время; ниже место и «раз»; затем код и «было → стало». Правый столбец одной ширины у всех карточек — время, «раз» и статус на одной вертикали. Автор — в карточке записи.
