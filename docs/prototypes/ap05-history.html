Что это и зачем

«Новости» отвечают на вопрос что произошло (создано, закрыто, выпущено). История отвечает на что именно поменялось: статус «был → стал», какие поля правили, сколько раз запись переписывали. Это нужно, чтобы разбирать «почему спринт так долго висел» и ловить молчаливые перезаписи.

Сейчас в v2 это видно только по одной записи — вкладкой «История» в паспорте. Общего журнала по проекту нет.

v1выбор записи (спринт / ADR / задача) → версии с диффом полей
v2 сейчасвкладка «История» в паспорте любой записи
Предлагаетсяжурнал переходов по проекту + та же лента версий у записи
только смена статуса

Каждая строка — переход статуса из SCD2-истории (task_status_versions, decision_status_versions, history_sprint). Клик — паспорт на вкладке «История». Правки текста без смены статуса — значком «изменено», без диффа тела.
