Шаг 1 SPRINT_LORE_PRODUCT_BACKLOG/SUPERTAGS-SPIKE: поток «#тег» в редакторе и экран «сущности по тегу с полями». Модель — по решению ред. 2.0: костяк полей у типа, а свободные поля тега — атрибуты ребра TAGGED_WITH без истории; в тексте один токен [[GEOID#тег]]. Только раскладка: бэкенда нет, записи и значения — заглушки. Ценность (слово владелицы): «метапроектирование без релизов».
