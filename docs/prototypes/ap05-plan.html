Что это и зачем

План отвечает на вопрос «что и к какой вехе мы везём, и успеваем ли». Дорожка — веха продукта, полосы — её спринты по плановым датам, красная черта — сегодня. В v2 сейчас есть только «Таймлайн» спринтов: полосы без вех, без группировки и без подписей дат.

Старая план-доска (дорожки, секции, контрольные точки) снята решением D-2026-LORE-PLAN-BOARD-REMOVED — её данные не переносятся. Поэтому план строится только из вех и спринтов, без отдельных сущностей плана.

Вех OMILORE открыто 9W1–W6, O1 (client-safe), O2, O3; исторические (заморожены) свёрнуты
Дат у вех неттолько текст: «прогноз Q4 2026», «прогноз Q1 2027» — ставим ромб на конец квартала пунктиром
Сделано в RM-U1…U3прототип v4, фильтр продукта, продукт у вехи; не сделано: портфель (RM-U4), телефон (RM-U5)
закрытв работене начатсегодня / план просроченвеха (пунктир — квартал из текста)

Честно о данных: (1) у вехи O1 срез roadmap насчитал 36 спринтов, а id прочитаны у 3 — остальные пришли пустыми (гипотеза: спринты других проектов вне скоупа агента); на экране это «ещё 33 спринта не видны вам», а не «их нет»; (2) у 7 закрытых спринтов плановые даты в будущем (S5, S7B, S8, S9…) — план не обновляли после закрытия; полоса рисуется по плану, а метка «закрыт» — по факту.

Развилки для владельца

P1 · Где живёт план

В v1 — отдельный раздел «План». В v2 у списков есть виды (Список, Доска, Таймлайн…).

P2 · Что такое дорожка

v1 — дорожки по компонентам; прототип RM-U1 v4 — по вехам продукта.

P3 · Дата вехи на шкале

У всех открытых вех дата — текст («прогноз Q4 2026»); квартальный прогноз — решение D-2026-LORE-ROADMAP-IS-QUARTERLY-PROCESS.

P4 · Контрольные точки

17 контрольных точек v1 не переносятся вместе с план-доской.
