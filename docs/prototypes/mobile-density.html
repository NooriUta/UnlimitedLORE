Почему так, а не просто «уменьшить»

Сейчас высота элемента равна цели касания: 44 px растягивают чип, у которого подписи 11 px. Текст не растёт — растёт только обвязка, поэтому телефон и выглядит иначе, а не просто крупнее.

В предложении эти две вещи разведены: высоту задаёт содержимое, а палец получает своё — невидимой областью вокруг. По вертикали её расширять можно: между рядами есть просвет. По горизонтали — нет: там чипы стоят вплотную, и области наложились бы друг на друга.

Строка списка и кнопка остаются крупнее остального: по строке попадают вслепую при прокрутке, а кнопку ищут глазами.
