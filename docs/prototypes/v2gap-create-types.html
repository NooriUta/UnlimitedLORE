«+ Новая» для остальных типов

Что это. Сейчас человек в v2 может завести только спринт, ADR, задачу, решение, спеку и организацию. Боль, выгоду, работу, роль, фичу, веху, релиз, вопрос, документ и остальное заводят только агенты через MCP.

Зачем. Без этого VP-канва и профиль клиента в v2 останутся только для чтения: пробел «роль не задана» у 57 ценностей человеку не закрыть. Форма строится из модели — те же поля и связи, что в паспорте; обязательное помечено *.

Модель — shared/model/lore-model.json (develop 2d44feb5). Пути записи — по коду сервера и MCP. Списки выбора — живой снимок LORE 25.11.2026.
