S4-24 · «Редактировать всё» прототип раскладки · данные — настоящий ADR-LORE-022 с прода · сохранение не уходит на сервер
  1. Чтение: под заголовком — одна кнопка «✎ Редактировать» на всю запись (тексты + свойства). Карандаши у отдельных полей остаются для быстрой правки одного поля.
  2. Правка: бар паспорта превращается в полосу правки: «изменено N полей», «Отмена» и «Сохранить» наверху (липкая — видна при прокрутке длинного ADR). Все тексты — исходник MD, свойства раскрыты, связи — чипы с × и «+ добавить».
  3. «Сохранить» неактивна с причиной: «нет изменений» или «пустое обязательное: Название». Изменённые поля помечены. «Отмена» с изменениями — подтверждение со списком, что потеряется. Выход по Esc — то же подтверждение.
  4. Сохранение — одним действием: сервер получает все изменённые поля и связи; если часть не сохранилась, правка не закрывается и неудачные поля названы.
