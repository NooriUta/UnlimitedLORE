6 · Что не посчитано и почему

  • Даты мержа PR в LORE нет: у KnowPR нет ни merged_at, ни даты вообще, а у 6 релизов, в которые PR уехали, нет даты. PR по дням взяты из локальных git-клонов (только log, без fetch): UnlimitedLORE, miniLORE, volva. Клон aida-root отстаёт (последний коммит 2026-11-08), поэтому AIDA в дневной ряд PR не входит (за 30 дней по клону 88 PR); у MIDGARD, Datawanderers и miniLore_serverside клонов нет — PR для них не посчитаны.
  • Дата рождения решений неизвестна для 1 027 из 1148: история решений заведена бэкфиллом 08.11 около 13:00 UTC одним часом. Эти решения из ряда «новые решения + ADR» исключены; ADR взяты по первой версии истории. Поэтому связь «диалоги ↔ решения» (0,41, на приростах 0,13) слабая и в выводы не идёт.
  • Авторство перехода (changed_by) заполнено только с 09.11 (до этого null у 100% версий), поэтому сравнение harness — за 6 дней, а не за 30.
