  • Серьёзные ошибки логики:
    • принятые ADR (180 из 241) спрятаны как «закрытые»;

    • на телефоне касание абзаца сразу открывает правку;

    • выделение «утекает» в другие разделы.

  • Что заявлено, но в прототипе нет: флаг «новая навигация», режим встройки, лента «Активность» с агентами, «скрыто правами · кого спросить», экран «что LORE помнит обо мне», комментарии, входящие.

3. Средние — коротко

  • Группировка: предлагает поля, которых нет у раздела; нет «Релиза» и подгруппы; пресеты задвоены. НАВ
  • Релизы в фильтре: 60+ значений вперемешку — нужен порядок по дате, группы по проекту, «текущий / следующий». НАВ
  • Поиск по тексту: внутри списка искать нельзя — вкладка «Текст» в «+ Фильтр». НАВ
  • Вид раздела: у раздела нет вида по умолчанию (командный, переопределяемый личным). НАВ
  • «Код / превью / рядом»: режим «рядом» не живой — нужна задержка 250 мс. ЗАП
  • Плашка «несохранённые правки»: закрывает текст. ЗАП
  • Черновик: теряется при перезагрузке — хранить на сервере и предлагать «Восстановить». ЗАП
  • Граф: подписи налезают; рёбра подписаны английскими кодами при русских фильтрах; счётчик «Граф 7» расходится с «13 узлов». ЗАП
  • Völva: не похожа на Metabase — «нативный» не SQL; одно условие; один вид графика; клик уводит со страницы вместо меню действий. Вопрос записи по умолчанию малополезен — нужны шаблоны по типу записи. ЗАП
  • Языки запросов: их три — оставить чипы и MBQL Völva, конвейер — только сахар. ДЬЯ
  • Стартовый экран телефона: не отвечает на вопрос «что горит» — по умолчанию «В работе + блок». ДЬЯ
  • Агенты: не могут выполнить и проверить блок — нужен MCP-инструмент «выполнить блок». ДЬЯ
  • Шапка телефона: список начинается на 29 % экрана, текст записи — на 49 %. Фильтры — одной лентой, «Вид» и «+» — в FAB или «⋯». СКР
  • Касание: подсказки клавиш (kbd) видны и на сенсорных экранах. СКР
  • Иконки: зависят от CDN — без iconify шапка пустая. Держать спрайт у себя. СКР
  • Лицензия (гипотеза): Metabase OSS — AGPL; отдавать форк внешним клиентам по сети, вероятно, обязывает раскрыть исходники. Проверить у юриста. ДЬЯ

4. Где мы теперь лучше рынка

  1. Честный блок в тексте: своя свежесть, ↻, ошибка с причиной и списком допустимых полей. В Notion, Confluence и Dataview сбой выглядит как пустота.
  2. Аналитика, список и текст замкнуты в круг: из вопроса — «в текст», из ячейки — фильтр в URL, вопрос живёт в Markdown, агент правит тот же исходник.
  3. «Изменён · Сохранить / Сохранить как / Сбросить» одной полосой и запрет молча менять командный вид.
  4. Шаг 3 для завершающих статусов прямо в палитре («кем заменён», «причина»). Палитра на 10 пунктов по 46 px — нижний лист на телефоне.
  5. История «человек / агент» и «Вернуть как новую версию» — ни Notion, ни Confluence так не различают.
  6. Справка «клавиша → кнопка / жест» как обязательный контракт.

5. Сводный топ правок для v4

  1. Клавиатура не мешает кнопкам: обработка только на строке; выключатель однобуквенных клавиш; управление фокусом в окнах; e2e «Enter и Space на каждой кнопке».
  2. Телефон:
    • панель действий вместо шапки, тост над ней, нижние листы с учётом клавиатуры;
    • правка только через ✎ или долгое нажатие;
    • Völva — только просмотр, таблицы транспонировать;
    • фильтры одной лентой, стартовый вид «что горит»;
    • kbd скрыть, иконки держать у себя.
  3. Логика статусов и видов:
    • accepted у знаний = «действует»;
    • группы раскрыты, свёрнуты только закрытые;
    • одно правило счётчиков, знаменатель от скоупа;
    • группировка из полей раздела, подгруппа и «Релиз»;
    • вид раздела по умолчанию.
  4. Völva по-взрослому:
    • канон question: N, одна подпись на страницу, JSON без iframe, кэш;
    • меню действий по клику на ячейку;
    • шаблоны по типу записи;
    • чип «проекты записи · под вашими правами · скрыто N».
  5. Правка: слияние по блокам с диффом, «поверх» с подтверждением, черновик на сервере, живое «рядом», строки после смены статуса остаются на месте.
  6. Доделать заявленное: экран «Что LORE помнит обо мне», флаг «новая навигация», режим встройки, «Активность» с агентами и откатом, «скрыто правами · кого спросить», MCP «выполнить блок».

6. Что решить вам

  1. Völva в тексте: канон — только сохранённые вопросы (question: N), а короткая форма — сахар, который при сохранении превращается в вопрос Völva?
  2. Аналитика на телефоне: только просмотр результата, редактор вопроса — на десктопе?
  3. Однобуквенные клавиши: по умолчанию включены, с выключателем в настройках пользователя?
  4. Лицензия Metabase (AGPL) для встройки внешним клиентам — кто проверяет?
