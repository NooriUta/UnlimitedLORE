Где взять

Всё, что мы отдаём наружу, лежит в зеркале SeidrStudio на нашем git-сервере: репозитории только для чтения и выпуски с файлами. Нужна учётная запись на сервере — без входа страницы не открываются.

Репозитории — что есть что

репозиторийчто это
SeidrStudio/UnlimitedLORE LORE целиком: сервер, веб-интерфейс, подключение для ИИ-агентов (MCP), установщик и инструмент переноса данных. Отсюда же выпуски с дистрибутивами.
SeidrStudio/miniLORE Телефон: приложение для Android и шлюз машины, который показывает приложению живые сессии агентов. Здесь же выпуски шлюза.
SeidrStudio/miniLore_serverside Сервер miniLORE — связывает телефон, шлюзы машин и LORE. Ставится вместе с LORE по выбору.
SeidrStudio/lorekit Общие части веб-интерфейса: таблицы, паспорта, графики, плитки показаний, темы. То, из чего собран интерфейс LORE.
SeidrStudio/forgejo-mcp Мост между ИИ-агентом и git-хостом: позволяет агенту читать и вести PR, выпуски и журналы сборок. Форк, лицензия MIT.

Дистрибутивы — что скачивать

файлзачемгде
lore-migrate-linux-x64
119 МБ		 Установщик LORE одним файлом: окно по шагам, перенос данных, сам пакет внутри. Node внутри — доустанавливать нечего. Linux x86-64, Docker, ~5 ГБ места. выпуск LORE
lore-installer-<версия>.tar.gz
~350 КБ		 Лёгкий пакет для Linux: сценарий установки, compose, пример настроек, README и инструмент переноса. выпуск LORE
lore-installer-<версия>-windows.zip
~350 КБ		 То же для Windows: распаковывается без лишних программ, запускается из PowerShell. Нужен Docker Desktop в режиме Linux-контейнеров. выпуск LORE
lore-src-<версия>.tar.gz
~15 МБ		 Исходный код: нужен, если хотите собрать образы у себя, без нашего реестра. выпуск LORE
SHA256SUMS Подписи всех файлов выпуска — сверьте перед установкой: sha256sum -c SHA256SUMS. выпуск LORE
miniLORE-f1.12.86.apk
75 МБ		 Приложение для телефона (Android). Ставится вручную: разрешите установку из этого источника. Версии для iOS нет. выпуск v1.12.86
miniLORE-link-setup-0.3.81.exe
minilore-link_0.3.81_amd64.deb
minilore-link-linux-0.3.81.tar.gz		 Шлюз машины: показывает телефону живые сессии агентов этой машины. Ставится на каждую машину, где работают агенты. выпуск link-v0.3.81

Порядок установки: скачать установщик LORE → запустить и пройти окно → поставить шлюз на свою машину → (по выбору) включить сервер miniLORE в том же окне и поставить приложение на телефон.

Выпуск LORE с дистрибутивами публикуется на странице выпусков репозитория SeidrStudio/UnlimitedLORE. Приложение для Android выпускается отдельно, в репозитории miniLORE; версии для iOS нет.
