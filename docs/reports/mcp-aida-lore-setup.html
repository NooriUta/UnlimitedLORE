aida-lore MCP

как работает · какие есть варианты настройки · 13.11.2026

Коротко: Claude Code сам запускает MCP-сервер aida-lore отдельным процессом на ноутбуке. Сервер получает токен в Keycloak под клиентом lore-mcp-full и ходит в бэкенд LORE на сервере. Канон настройки — одна запись в ~/.claude.json (user-скоуп).

Сейчас: MCP собран из 2648f661, бэкенд отвечает, расхождения нет, запись в LORE проходит, машина LORCETUS передаётся.

Берётся первый найденный сверху вниз. Поэтому забытый .mcp.json в чекауте молча выигрывает у канона: 13.11 в нём лежал старый секрет, и все вызовы получали 401.

ВариантГдеКогда брать

4. Клиенты Keycloak — свой у каждого harness

lore-mcp-full — Claude Code · lore-mcp-full_kimi — Kimi · lore-mcp-full_<harness> — остальные. Чужой клиент брать нельзя: действия в графе припишутся не тому агенту.
