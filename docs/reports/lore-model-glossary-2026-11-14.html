1. Что что значит (MD-01)

Живой тип — в проде есть записи база и код его пишет или читает код (прямо по имени, через срез или через ребро). Пишущие места — найдены разбором Java (INSERT/UPDATE/CREATE EDGE с этим именем); эндпоинт — ближайший @Path выше места записи, инструмент MCP — по совпадению пути. Читающие — срезы LoreSlices (срез с рамкой — его берёт телефон miniLORE по контракту minilore-phone-api.json), паспорт v2 по модели, прямые SELECT/обходы.
