# v1.14.0 — новая админка, ошибки вместо «пусто», мобильная раскладка, состояние экранов в URL

Минорный релиз: 21 PR (#729–#754) после v1.13.1. Главное — уборка админки по одобренному прототипу и правило «сбой загрузки ≠ пусто» по всему LORE, закреплённое гвардами.

## Админка v2 (`SPRINT_LORE_ADMIN_HOUSEKEEPING`)

- **Раскладка по прототипу** `docs/prototypes/admin-v2.html` (#746, #749; AH-04/AH-05). Полоса состояния системы на всех вкладках, честные счётчики в навигации («?» — не смогли проверить), «где я» на телефоне и лента вкладок с подписями групп. «Люди» — список и карточка рядом (на телефоне — на весь экран), таблицы на телефоне становятся карточками, тап-цели 40px.
- **Все realm-роли Keycloak видны и выдаются** (#729; AH-02). Раньше мост пускал только admin/viewer, а карточка не показывала остальные роли. super-admin по-прежнему только из консоли KC.
- **Файл админки разрезан на модули по вкладкам** (#736; AH-03) — поведение не менялось, сверено построчно.
- Инвентаризация 120 функций админки (`admin-v2-inventory.md`) — внедрение сверено с ней, пропавших функций нет.

## Ошибка видна, а не «пусто» (`AH-07`)

Четыре зоны (#730, #737, #742, #745): транспорт (403 больше не превращается в «LORE недоступен»), лента новостей, продуктовые срезы, админка, аналитика (16 срезов через allSettled), «Знания», BRAGI-аналитика, TYR, bench, «Спринт/Компонент не найден» (только на 404). Гвард `no-silent-catch` запрещает `.catch(() => {})` и подмену упавшего значения пустым.

## Мобильная раскладка и состояние в URL

- **9 экранов на телефоне** (#750; AH-08): TYR, Timeline, Evolution, BRAGI-план, паспорт компонента, Biblio, аналитика, вехи, редактор публикации. Выбор проекта на телефоне — в «⋯», ресайз на pointer events.

Гварды: шрифт < 9px, hex-альфа к цветовой переменной, MD-поле не голая textarea, тап-цели, MD-превью. Исправлены нарушения (#735, #743, #752): чипы BRAGI-плана снова с рамкой, MD-поля через TipTapField, превью через MartProse, мёртвые ссылки BRAGI ведут куда обещают, песочница HTML читается в светлой теме, экран «Подключения» переписан на `minilore-link`.
